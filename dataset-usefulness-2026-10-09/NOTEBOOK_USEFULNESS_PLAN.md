## Priorities that provide immediate value

1. Publish the verified description gaps in the two existing datasets; there is already an audience attaching ChEBI/LIPID MAPS.
2. Add a small preview table or standalone CPU example only when its source/terms and values are actually verified. Preserve existing arrays and data versions. Do not fabricate rows that look like real compounds.
3. Recover the missing historical ChEBI/LIPID MAPS build record before claiming per-source counts, coverage, generator compatibility or broader rights.
4. Use one authoritative experiment table linked to exact accepted or completed receipts. Display a failed experiment as a failure, and a prepared candidate as unexecuted.
5. Prefer meaningful improvements in run instructions and experiment interfaces over length, ornamental diagrams or repeated parameter variations without a question they resolve.
