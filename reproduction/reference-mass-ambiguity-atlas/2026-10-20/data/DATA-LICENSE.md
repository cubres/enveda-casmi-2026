# Reference exact-mass ambiguity atlas: component terms

This atlas is derived only from the public ChEBI reference shard pinned in
`REFERENCE_INPUTS.json`. No spectra, competition targets, labels, model weights
or predictions are included or queried.

ChEBI molecular records and derived representations retain CC BY 4.0 terms,
source identifiers, sergiomalv's attribution, ChEBI release 255 attribution and
the Hastings et al. citation. Retain the exact `SOURCE_ATTRIBUTION.md` and
`SOURCE_COMPONENT_LICENSE.md` supplied here. The frozen fingerprint mask keeps
its separate documented competition-training-derived component terms; this
atlas does not grant new rights over that mask or underlying data.

Additional changes are directed reference-mass-window enumeration, exclusion
of equal public canonical-group digests, exact binary-fingerprint intersection
and union counts, binary Jaccard/cosine ratios, and per-reference coverage
counts. The output does not contain a copied mask or fingerprint matrix. These
transformations do not establish MS2 retrieval quality, chemical novelty,
validation recall, competition eligibility or a score improvement.

Use **Other / per-component terms** for the aggregate. There is no blanket CC0,
Apache or new blanket CC BY grant over all components. Newly authored code is
Apache 2.0 as marked in source and `LICENSE-SOURCE`; that code license does not
relicense data or third-party libraries.
