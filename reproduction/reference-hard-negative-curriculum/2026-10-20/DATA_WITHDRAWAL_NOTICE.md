# Withdrawal of generated curriculum tables · 21 October 2026

The earlier public version of this package included generated CSV tables and row-level JSON derived using a frozen 10,395-bit fingerprint mask associated with CASMI training data. An independent read-only review confirmed the output hashes and mechanics, but could not establish the mask component's exact redistribution rights.

The derived files are therefore removed from the current `main` branch pending rights clarification. This is a precautionary hold, not a determination that the earlier publication infringed a licence. The preserved source files and synthetic demo remain available under their marked code terms. The CPU run receipt is retained as mechanics/resource evidence only; it is not a score or model-quality result.

The repository's earlier commits are not rewritten and may still contain the former file blobs. Please do not retrieve, redistribute, or train on those historical output copies until the relevant component terms are resolved. No notebook, Kaggle slug, notebook version, or notebook identity was changed.
