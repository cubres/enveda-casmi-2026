# Before fitting: ask what a fragment feature explains

An original optional companion for [prvsiyan/analog-propagation-casmi-2026-baseline](https://www.kaggle.com/code/prvsiyan/analog-propagation-casmi-2026-baseline). Read [COMPANION.md](COMPANION.md) or open [PREVIEW.html](PREVIEW.html) for the full visual preview. [COMPANION.html](COMPANION.html) is an equivalent article fragment; its preview stylesheet is presentation only.

The example uses invented inputs and the exact MIT-licensed dependency in [DEPENDENCIES.json](DEPENDENCIES.json). Obtain that helper from the pinned commit, then run `python3 -I -B toy_example.py --tool /your/path/fragment_consensus.py`. The script verifies the helper source digest before loading it, performs no network calls and prints only its invented result. It does not run the active notebook, a model, an evaluation harness or a submission. Results are preserved in EXAMPLE_RESULT.json.

The versioned PNG is AI-generated concept art, with [exact provenance](ARTWORK_PROVENANCE.json). The SVG diagram is original conceptual explanation, generated by the supplied script from fixed text and toy numbers. No medical record, real spectrum, task identity, agent package or third-party notebook implementation is included. Existing notebook cells, identities, metadata and older artwork remain preserved. Integration is a separate reviewed coordinator proposal.
