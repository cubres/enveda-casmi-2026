# Credit, terms and provenance

This package's mass-search, row-order digest, packing checks, tie reporting, synthetic fixture, tests, prose and SVG were written specifically for this companion. The scoring core is our original `block_balance_r2.py`, preserved from the separately reviewed 13 October source packet; its exact hash is in the freeze. It implements elementary score equations and contains no third-party code or molecular definitions. MIT applies solely to this original package.

The user highlighted [Aryan Awasthi's COCONUT Morgan/MACCS dataset](https://www.kaggle.com/datasets/aryanawasthiteykik/casmi26-coconut-morgan-maccs-fingerprints) and [spectrum-to-fingerprint model](https://www.kaggle.com/datasets/aryanawasthiteykik/casmi26-spectrum-to-fingerprint-mlp). They motivated a portable, explicit interface. The coordinator's exact primary captures on 12 October record a declared 436,389-row mass-sorted bank, 277-byte fingerprints, and a matching V2 2,216-output model. The captured cards display CC BY-NC-SA 4.0. These are prior publisher declarations, not current tensor/code/packing qualification or a grant to this MIT package. The exact pages were inaccessible to the public web reader on 13 October; this task performs no network refresh.

Credit also belongs to [prvsiyan's COCONUT candidates](https://www.kaggle.com/datasets/prvsiyan/coconut-casmi26-candidates) and [COCONUT's contributors](https://coconut.naturalproducts.net/). No source data or structures from either are bundled. Existing derivative notices do not change merely because another upstream release has different terms. Competition training structures must stay in the user's private environment rather than this public companion.

Primary numerical references, previously reviewed in the campaign:

- [NumPy searchsorted](https://numpy.org/doc/stable/reference/generated/numpy.searchsorted.html): explicit lower/upper insertion sides.
- [NumPy packbits](https://numpy.org/doc/stable/reference/generated/numpy.packbits.html) and [unpackbits](https://numpy.org/doc/stable/reference/generated/numpy.unpackbits.html): explicit bit order; no guessing from NumPy's default.
- [RDKit MACCS header](https://github.com/rdkit/rdkit/blob/master/Code/GraphMol/Fingerprints/MACCS.h): 167 positions for numbered keys 1–166. No key definitions or SMARTS are included.
- [RDKit Morgan generator documentation](https://www.rdkit.org/docs/source/rdkit.Chem.rdFingerprintGenerator.html): a width is not a complete generator convention. This package generates no chemical fingerprints.

The prospective block-balancing hypothesis is credited to the current [independent public implementation](https://github.com/Isaackjoshua/casmi-2026/blob/main/src/multi_fingerprint.py), which also uses a Morgan-radius-3 block. No source from it is bundled, and its reported effects do not establish this companion's quality. Our source scorer uses a different declared two-block space, masks the two dummy positions, and fixes weight 0.30 without a search.

There are no results to relicense or report: this author has performed source construction and static syntax inspection only, with no NumPy/test execution, fitting, model imports, real numeric rows, authentication, native launch, submission or publication. Any later real-data use needs its own exact provenance, current eligibility and observed receipts. A synthetic test result must remain labeled synthetic.
